📌 Project Overview

This project demonstrates an AI-assisted healthcare support system that analyzes patient information and displays illustrative risk indicators.

The system is designed to demonstrate how Artificial Intelligence can support healthcare professionals in reviewing patient data and prioritizing care.

🎯 Project Objectives

- Demonstrate patient data analysis.
- Identify illustrative risk patterns.
- Support clinical decision-making workflows.
- Display patient information through a dashboard.
- Demonstrate machine learning model evaluation.

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Random Forest Classifier

⚙️ Installation

Install the required libraries:

pip install -r requirements.txt

▶️ Run the Application

Run the following command in your terminal:

streamlit run app.py

The application will open in your web browser.

📊 Features

- Patient Information Dashboard
- AI-Based Illustrative Risk Analysis
- Machine Learning Model Evaluation
- Feature Importance Visualization
- Clinical Review Interface

🔄 System Workflow

Patient Data → Data Preparation → AI Analysis → Clinician Review → Care Action

⚠️ Disclaimer

This is an academic demonstration using synthetic data.

It is not a clinically validated medical system and must not be used for real-world diagnosis or treatment decisions.

AI-generated outputs are illustrative and require independent clinical judgment.
